# Plot Planner

SillyTavern 확장. 다음 답변을 쓰기 전에 서로 다른 개요를 여러 개 받아 보고, 고치거나 골라서 그 개요대로 쓰게 합니다.

## 설치

확장 패널 → Install extension → 아래 주소 입력

```
https://github.com/kkkangkkang-creator/Plot-Planner
```

## 사용법

1. 입력창에 메시지를 쓰고(비워둬도 됨) 전송 버튼 옆 분기 아이콘을 누른다.
2. 지금까지의 프롬프트를 바탕으로 개요 n개가 생성된다. 각 개요는 전개 / 설정 / 끝 으로 나뉜다.
3. 개요를 직접 고치고, 왼쪽 번호를 눌러 선택한다.
4. "이 개요로 전송"을 누르면 고른 개요가 주입된 채로 전송된다.

- **새로 생성**: 개요를 전부 새로 받는다.
- **더 보기**: 기존 개요와 겹치지 않는 개요를 추가로 받는다.
- **다시 시도**: 생성이 실패했을 때(429 등) 같은 작업을 다시 한다. 이미 받은 개요는 남는다.

## 실패와 재시도

고른 개요는 그 답변 자리에 붙어 있다. 본문 생성이 실패해도 재생성·스와이프하면 같은 개요가 다시 들어간다. 새로고침해도 유지되고, 다음 메시지를 보내면 자동으로 풀린다. 적용 중일 때는 아이콘 색이 바뀌며, 패널에서 직접 해제할 수 있다.

## 설정

| 항목 | 설명 |
|---|---|
| 연결 프로필 | 개요 생성에 쓸 프로필. 기본은 현재 연결 (Connection Manager 필요) |
| 개수 / 방식 | 한 번에: 호출 1번. 하나씩: 앞 개요와 겹치지 않게 1개씩, 호출이 개수만큼 |
| 최대 토큰 / 온도 | 온도는 연결 프로필을 골랐을 때만 적용 |
| 주입 깊이 / 역할 | 고른 개요를 넣을 위치 |
| 개요 생성 지침 | `{{count}}` = 개수 |
| 주입 템플릿 | `{{plot}}` = 고른 개요 |

## 참고

- 개요를 만들 때는 이번 입력이 아직 채팅에 들어가기 전이라, 그 입력의 키워드로만 켜지는 월드인포 항목은 개요 단계에 반영되지 않는다. 본문 생성 때는 정상 반영된다.
